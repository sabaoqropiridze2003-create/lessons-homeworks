# Todos Explorer

A static front-end application that fetches todo records from `https://jsonplaceholder.typicode.com/todos`.

Features:
- List all todos by title
- Search todos by title
- Filter todos by `userId`
- Filter todos by `completed` status
- Pagination for the list view
- Detail page for each todo showing all fields

## Run locally

1. Open `index.html` in a browser, or run a local static server.
2. If you have Python installed, start a server from this directory:
   ```sh
   python -m http.server 8000
   ```
3. Open `http://127.0.0.1:8000` in your browser.
